Развернутая инструкция

В этом уроке мы разберем процесс разработки — от получения "ключей" до запуска первого кода на вашем компьютере.

Регистрация бота в BotFather

Чтобы ваш бот появился в Telegram, его нужно зарегистрировать через официального "отца ботов":

  • Найдите в поиске @BotFather и нажмите /start.
  • Отправьте команду /newbot.
  • Придумайте название (имя, которое видят все) и username (уникальный адрес, заканчивающийся на _bot).
  • После этого вы получите API TOKEN — это секретный ключ. Сохраните его.

Подготовка рабочего места

Вам понадобится установленный Python. Откройте терминал (командную строку) и установите библиотеку aiogram, которая упрощает работу с API Telegram:

pip install aiogram

Написание базового кода

Создайте файл main.py и вставьте в него стандартный шаблон. Этот код заставит бота отвечать "Привет!" на любое текстовое сообщение.

from aiogram import Bot, Dispatcher, executor, types

# Вставьте сюда свой токен от BotFather
API_TOKEN = 'ВАШ_ТОКЕН_ЗДЕСЬ'

bot = Bot(token=API_TOKEN)
dp = Dispatcher(bot)

# Обработчик любых текстовых сообщений
@dp.message_handler()
async def echo_message(message: types.Message):
    await message.answer("Привет! Я твой первый бот.")

if __name__ == '__main__':
    executor.start_polling(dp, skip_updates=True)

Запуск и проверка

Запустите ваш скрипт через редактор кода или командой в терминале:

python main.py

Теперь зайдите в Telegram к вашему боту и напишите ему любое сообщение. Он должен мгновенно ответить!

Важно: Никогда не передавайте свой API TOKEN посторонним лицам и не выкладывайте его в открытый доступ, иначе любой сможет управлять вашим ботом.
